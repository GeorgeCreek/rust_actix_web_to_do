After install, open pgAdmin from the app menu (or the web UI if you installed that), then register a server with:

Field	Value
Host name: Postgres
Host: localhost
Port: 5432
Maintenance database: to_do
Username: username
Password: password
Then: Servers → your server → Databases → to_do → Schemas → public → Tables → to_do_items → View/Edit Data → All Rows.

Those credentials match your docker-compose/ingress/.env setup. Postgres must be running (docker compose up -d postgres from the project root).
